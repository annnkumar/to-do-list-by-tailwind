# Colorful Todo List

This project is a Colorful Todo List application built using HTML and styled with Tailwind CSS. It provides a user-friendly interface for managing tasks with different priority levels.


## Technologies Used

- HTML
- Tailwind CSS


## Installation

1. Clone the repository:
   ```
   git clone https://github.com/annnkumar/to-do-list-by-tailwind.git
   ```

2. Navigate to the project directory:
   ```
   cd to-do-list-by-tailwind
   ```

3. Open the `src/to-do-list/to-do.html` file in your web browser to view the application.

## Usage

- To add a new task, type in the input field and click the add button.
- Tasks can be marked as completed by clicking the corresponding button.
- You can clear completed tasks using the "Clear completed" button at the bottom of the task list.
